# CSFriendCode 
### Parse CS Friend Codes from nicknames on discord servers and open them in the browser.

![screenshot](https://github.com/user-attachments/assets/05492c1a-1f45-4450-9f4b-9b07b35a630c)

## What is a CS Friend Code
that will be the "invite code" to share to other players when you want to invite them in Counter-Strike 2.
See this guide for more info : [https://steamcommunity.com/sharedfiles/filedetails/?id=3260276914](https://steamcommunity.com/sharedfiles/filedetails/?id=3260276914)
